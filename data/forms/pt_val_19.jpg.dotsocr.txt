# Instruções para preenchimento do formulário (PDF preenchível)

Necessário:

1. Aplicativo leitor do arquivo PDF (ex.: Acrobat read e outros);

2. Opção caps lock ativado (CAIXA ALTA – LETRAS) para preenchimento.

## 1ª Fase - Modo de preenchimento:

1. Como iniciar o preenchimento do formulário em PDF preenchível:

1.1. Utilize o mouse para selecionar o primeiro campo a ser preenchido.

1.2. Para pular para próximo campo:

1.2.1. Pode utilizar o mouse ou tab.

1.3. Para iniciar o preenchimento do formulário aberto no Adolbe Acrobat Reader

1.3.1. Para iniciar utilize o mouse clicando dentro do quadrado que fica em frente a palavra razão social

1.3.1.1. Para desmarcar é somente utilizar o mouse para desmarcar a escolha.
